三花桌宠 · Windows 11 原型

启动
1. 安装 Windows 版 Python 3.10 或更新版本（建议 3.12）。
2. 双击 start_cat.bat。首次运行会创建 .venv 并下载 PySide6，需要联网。
3. 后续启动无需重复安装。无需管理员权限。

也可在 Windows PowerShell 中运行：
  py -3 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe desktop_cat.py

操作
- 左键按住会抱起猫咪，四肢自然下垂；拖动时轻微晃动，停住后慢慢稳下来。
  将猫咪脚下移到普通窗口的可见上沿附近（约 32 个逻辑像素）松手，会吸附并趴在窗口上。
  没有可用窗口时，自动／底沿模式回到底部，自由悬浮模式保留松手位置。
  右键“现在做个动作 → 趴到附近窗口上沿”也可寻找附近窗口（范围 160 个逻辑像素）；
  找不到合适窗口时保留当前位置。“回到任务栏／屏幕底沿”可退出窗口待机。
- 右键猫咪或系统托盘图标，切换位置模式、大小或退出。
- 右键“走路效果”可随时切换：
  · 对角交替走路（新 8 帧）：默认使用此次确认的完整循环，左右独立毛色，尾巴竖起。
  · 旧 8 帧翘尾巴（脚掌锚定）：保留之前的脚掌锚定版本。
  · Deform（整图柔性变形）：保留上一版，完整猫图连续变形。
  · 最初动画版（8 帧）：保留第一版左右走路的全部原始帧和播放顺序。
  · 整理后的动画版（4 帧）：保留后来对齐头部、整理过步态的版本。
  选择会自动保存，重启后沿用。切换效果不会重置当前巡逻目标或舔毛进度。
  本次更新首次启动会自动切到新的 8 帧版本，此后仍记住手动选择。
- 程序内走路速度为原始版本的 2 倍，比上次的 1.5 倍再快约三分之一；新八帧每圈 2 秒。
  新版身体接近匀速前进，只有约 ±8% 的轻微步伐节奏，不再每一帧都减速到停住。
  腿部补偿身体与脚步的位置差，支撑脚保持地面锚点；上身轻微起伏，翘尾巴缓慢摆动。
  休息、舔爪和转身时长保持原设置；素材目录的 2 fps 预览仍供逐帧检查。
- 坐姿和舔爪按头部比例缩放到原素材的 66%，脚底位置保持一致。
  左右行走停止时，各经过两张转身坐下的过渡图；起步时反向播放起身转向。
  转身期间暂停水平移动和行为计时，坐稳后再开始休息、舔爪或继续巡逻。
- 新增三套待机：趴着休息、仰躺放松、侧卧打盹，可在右键“现在做个动作”中选择。
  参考 Reference_photo 中真实猫咪的脸型和花纹，保持现有卡通画风；每套四张原画，
  轻微呼吸和慢眨眼，按 1→2→3→4→3→2→1 循环，每圈 3.2 秒。
  三套素材已经按现有桌宠大小和底沿打包，运行时不再重复缩小。
  巡逻休息时会随机采用其中一种姿势，再继续舔爪或原方向行走；自由悬浮也可随机休息。
  取消巡逻后不会自动切换新休息动作，但仍可手动试播。
- 日常活动／撒欢期间跨全部显示器巡逻，到整条路线尽头才掉头；各显示器独立跟随任务栏。
  显示器按位置排序，同高度相邻屏幕连续经过边界；不同高度、上下排列或带有
  缩放坐标空隙的屏幕在边界接续到下一块屏幕的底沿，不在空白区域行走。
  高低屏之间目前直接接续落脚位置，还没有跨高度跳跃动画。
- 较长路线会随机选一个中途停靠点，坐一会儿、舔爪，再继续原方向；不会因为
  旧版随机走路时长结束而提前折返。短路线直接走到边缘。
- 右键取消“自主生活（休息、活动、偶尔撒欢）”可让她安静坐着；“现在做个动作”可手动试播。
- 拖动或打开菜单时暂停自动行为；抱起状态仍会眨眼和随拖动晃动。
  抱起会取消尚未完成的转身、翻身和旧巡逻停靠点，松手后先落稳，再恢复活动。
- 窗口待机使用独立的四帧趴窗沿素材，前爪略微垂下，慢眨眼和轻微呼吸。
  新增“骑在窗框上放松”：两只外侧脚下垂，另外两只搭在窗框上，尾巴自然向下耷拉。
  两种待机均保留，可从右键“现在做个动作”选择；透明素材使用独立支撑线对齐窗沿。
  猫咪会跟随同一窗口移动、缩放；开启巡逻时会在趴姿、骑坐休息和短距离散步之间切换。
  窗口上选“向左走／向右走”也会留在当前窗沿行走；到边缘、遮挡处或走完一小段后休息。
  使用已有左右独立花纹的脚掌锚定步态，窗沿步速比地面巡逻慢；五种走路效果仍可切换。
  关闭巡逻会停下休息，仍留在窗沿。窗口太低、下垂尾巴容不下时保留较浅的趴姿。
  “从窗口跳下”或“回到任务栏／屏幕底沿”会触发蹲低准备、腾空、前爪着地、屈腿缓冲。
  窗口关闭、最小化、移出可用显示范围或支撑位置被其他窗口遮住时，直接进入腾空下降。
  连续三次原生窗口读取失败也会退出吸附，单次瞬时失败保留位置。
  只选择容得下猫咪且上方空间足够的窗口顶沿；最大化到屏幕顶部的窗口通常没有足够空间。
  坐姿、舔爪和左右走路可在窗沿进行；选择侧卧、仰躺等地面动作会先跳下，再执行。
  拖到另一窗口可重新吸附；跳跃中也可随时按住抱起，取消原来的下降。
- 新增“跳上／爬上附近窗口”和“跳到另一扇窗口”菜单动作。
  开启巡逻后，在地面休息时会尝试爬上可达窗口；窗沿休息后有机会换窗口或跳下。
  每次探索后休息约 12～24 秒，不会连续反复跳跃；关闭巡逻后仅手动触发。
  高处采用：蹲低起跳 → 快速交替攀爬（淡残影）→ 勾边、拉起、转水平、站稳 → 窗沿待机。
  附近窗沿采用弧线短跳，再勾边翻上；翻上阶段按每张原画的前爪接触线对齐窗口上沿。
  落点须足够宽且无遮挡，沿途须在显示区域内；允许连续多屏之间移动，不跨越显示器空隙。
  当前 220 像素尺寸的上攀高度上限为 880 逻辑像素，横向距离上限为 600 像素。
  没有可达窗沿时保留原动作；目标关闭、被遮挡或突然移远时取消，空中则重力下降着陆。
  小幅移动目标会平滑跟随；拖动立即中断，菜单暂停，空中请求的新动作在到达后执行。
- 跳跃使用按时间积分的重力：加速度 760 逻辑像素／秒²，最高下降速度 560 逻辑像素／秒。
  主动跳下准备 0.28 秒，轻微蹬起后加速下降；约 500 像素的下降本身需要 1.3 秒左右。
  前爪接触 0.16 秒、屈腿缓冲 0.26 秒，随后转回坐姿或继续请求的动作；不会越过地面。
  从高处拖放时也使用重力下降，接近底沿的小位移仍平滑归位；自由悬浮不主动下降。
  打开菜单暂停动作，抱起立即取消跳跃；任务栏高度变化时更新着陆位置。
- 新增柔和接触阴影：坐着较窄，走路、趴卧较宽，窗口顶沿使用较薄的阴影。
  抱起和自由悬浮时隐藏地面阴影；回到底沿时逐渐显现。
- 自动模式：任务栏隐藏时坐在屏幕底沿；任务栏出现时向上移动。
- 固定屏幕底沿：不跟随任务栏高度，任务栏出现时可能与猫咪重叠。
- 自由悬浮：保留拖动后的位置。
- 自由悬浮时可随机眨眼、舔爪、趴卧休息；手动选走路会切回自动底沿模式。
- 预留底边 3 个逻辑像素，避免阻挡自动隐藏任务栏的唤出区域。

动作转换安排
- 常规主链：左／右走路 ↔ 坐下 ↔ 趴着 ↔ 侧卧 ↔ 仰躺。
  例如仰躺时要求走路，会先侧卧、翻回趴姿、坐起，再起身转向走路。
- 舔爪从坐姿进入，结束回坐姿；更换左右行走方向也经过坐姿转向。
- 窗口待机接在趴姿之后：坐下 → 趴着 → 趴窗沿 ↔ 骑坐窗框。
  窗沿起步会先收回垂下的脚，经过趴姿、坐起与转身；每个姿势按自己的接触线贴住窗沿。
  离开窗口：蹲低准备 → 腾空下降 → 前爪着地 → 屈腿缓冲 → 坐姿或后续动作。
- 抱起优先级最高：任何动作立即进入抱起，清空旧转换。
  高处松手到地面：抱起 → 腾空下降 → 着地缓冲 → 坐下；近地面松手则直接坐下。
  松手到窗口：抱起 → 坐下 → 趴着 → 趴窗沿。
- 普通转换串联现有的完整姿势，每段 0.22 秒；行走与坐姿之间保留已有两张转身图。
  转换期间暂停自主移动与动作计时，完成后再开始目的动作；没有将两张猫图叠化。
  中途换动作从当前显示的姿势重新规划，取消旧目的动作；不会先把旧翻身播完。
  趴卧之间目前通过这些关键姿势衔接，尚未逐对绘制额外的翻身中间帧。

实现范围
- 新攀爬原画由内置 imagegen 生成，位于 output/imagegen/window-climb-v1/。
  launch/prompt.txt、mantle/prompt.txt 为完整提示词，各自 source-sheet.png 保留生成原图；
  tools/package_window_climb.py 裁切、配准并输出八张透明帧，不镜像花纹。
  window_transfer.py 负责可达落点、短跳轨迹、三段攀爬及逐帧前爪接触锚点。
  快速攀爬交替帧为 20fps，运动模糊为 Qt 低透明度短拖影，勾边后关闭。
- 骑坐和跳跃素材位于 output/imagegen/window-actions-v1/straddle、jump，使用 imagegen 内置工具生成。
  source-sheet.png、prompt.txt 保留原图及完整提示词；tools/package_window_actions.py 负责透明帧提取、
  等比缩放、眨眼配准与打包。旧趴窗沿与所有旧走路素材保留，没有镜像两侧毛色。
  跳跃四张原画分别对应准备、腾空、前爪着地、屈腿缓冲；腾空时长由实际高度和重力决定。
  window_motion.py 计算带速度上限的重力运动；window_perch.advance_perch 限制在同一可见窗沿区间内移动。
- 新交互素材位于 output/imagegen/interactions-v1/held、perch，使用 imagegen 内置工具生成。
  source-sheet.png、prompt.txt 保存原始图与完整提示词；保留原照片和旧动画。
  tools/package_interactions.py 仅裁切、等比缩放、配准及打包，四帧统一脸部尺寸；
  PNG、透明 WebP、共享调色板 GIF 和动画元数据位于各素材目录。
  抱起以胸部为支点进行小幅整图旋转，跟随拖动速度并衰减回正，不拆分四肢。
- action_routes.py 规划姿势顺序；pose_transition.py 记录每张过渡图对应的动作，支持中途改选。
  pet_effects.py 生成低透明度接触阴影、计算抱起晃动；猫与阴影先合成到同一离屏图后显示。
- window_perch.py 每 100ms 只读枚举窗口、可见边框、显示器和遮挡顺序。
  优先按显示器设备名匹配；Qt 返回型号名时，按唯一的屏幕原点匹配，再换算物理／逻辑坐标。
  修复 LEN T24h-20 等副屏型号名与 DISPLAY2 不一致导致无法吸附的问题；任务栏共用此匹配。
  排除桌面、任务栏、工具窗口及本程序作为支撑面。
  不激活、移动、缩放或修改其他应用窗口，不安装系统钩子；无需额外运行依赖。
- 新待机素材位于 output/imagegen/rest-idles-v1/prone、supine、side。
  imagegen 内置工具生成，source-sheet.png 和 prompt.txt 保存原图与完整提示词；
  PNG 透明帧、animation.json、透明 animation.webp 和 preview.gif 在各自目录。
  tools/package_rest_idles.py 对齐头部、统一尺寸并打包；首尾使用同一张图和共享 GIF 调色板。
- 透明无边框、置顶、不主动获取键盘焦点，不更改任务栏设置。
- 读取主/副任务栏实际窗口位置，每 100ms 检查一次，并平滑跟随。
- 枚举全部显示器，按设备名称或唯一屏幕原点匹配物理任务栏坐标与 Qt 逻辑坐标。
- 眨眼沿原路返回同一帧；舔爪按配置的往返序列播放。
- 当前默认素材：output/imagegen/walk-diagonal-left-v1、walk-diagonal-right-v1。
  右侧原画逐字节保留 walk-diagonal-cycle-v2 的八帧顺序；左侧由 imagegen 内置工具
  按对应姿势制作，替换另一侧花纹，source-01.png 至 source-08.png 和 prompt.txt
  保存在左侧目录。2 fps 关键帧时序沿用预览，应用按支撑脚同步前进和腿部接触位置。
  新版每次只显示一张完整姿势，不叠加两套腿；转身两帧也直接顺序播放，避免虚影。
  身体前进曲线与原来的脚步时序分开计算；下肢补偿两者的位移差，整段支撑期的
  同一只脚保持世界坐标不变。尾巴和身体通过连续网格轻微变形，脚底不受摆动影响。
  output/imagegen/turn-sit-v1 保存左右各两张转身图、原始图和 prompt-left/right.txt。
  tools/package_diagonal_app.py 负责缩放、脚底对齐、打包和记录支撑脚数据。
- 旧脚掌锚定 8 帧版：output/imagegen/walk-left-v3、walk-right-v3。imagegen 内置工具根据
  原 8 帧图编辑翘尾巴，两侧独立生成，原图与完整提示词 source-sheet.png、prompt.txt
  均保存在对应目录。没有覆盖旧版本。
  固定头脸与尾巴上部，躯干渐变衔接到腿部；8 个原画之间生成对齐支撑脚的过渡。
  animation.json 记录每段支撑脚、接触点、帧时长、身体前进量和落脚校正。
  身体位移 = 支撑脚在猫咪局部坐标内后移量的相反数；时间曲线控制换帧和位移，
  身体随蹬地加减速，不再匀速滑动。每段只以一只主要支撑脚为锚点。
  到边缘、中途停靠、任务栏移动、拖动或打开菜单时，步态和水平位移一起暂停。
  预乘颜色和透明度先分别加权再相加，避免混合中间帧透明度下跌、画面发亮。
  Qt 窗口整数坐标的余数在绘制时补偿，减少小尺寸时脚底的像素跳动。
- Deform 使用左右各一张完整猫图，路径为 output/imagegen/walk-left-v2/frame-01.png
  和 walk-right-v2/frame-01.png。左右毛色独立，不镜像整只猫。
  deform_renderer.py 用共享顶点的连续网格驱动腿部和尾巴，固定头部和上半身；
  没有拆分四肢、关节盖片，也不会逐帧更换花纹。透明网格内部边缘不重复叠加透明度。
  目前采用小幅柔性步态；单张画面无法表现腿部前后遮挡关系的变化，也不是严格的
  落脚锁定模拟，所以大步跨越的表现仍以逐帧动画为准。
- 五种走路效果共用巡逻逻辑，整帧在离屏缓冲后绘制。
  最初 8 帧版保留直接换帧，4 帧版沿用短暂过渡混合；旧动画本身的跳变可能仍存在。
  原来的 PySide6 依赖即可，无需安装新运行依赖。眨眼、舔爪保留现有序列素材。
  任务栏升降时暂缓水平行走并保留当前步态，落稳后继续。
- 之前的分块骨骼代码和 assets/rig 素材保留供开发对照，应用现在不加载它们。
- 走路效果使用 Qt 的用户设置保存；Windows 下位于当前用户注册表
  HKEY_CURRENT_USER\Software\DesktopCat\CalicoPet，键名 walk_style，无需管理员权限。
- 普通桌面窗口置顶不能覆盖 UAC 安全桌面或保证覆盖独占全屏程序。
- 当前支持 Windows 11 标准底部任务栏；第三方任务栏未验证。
- 当前开发环境是 Linux/WSL，尚需在真实 Windows 桌面验证任务栏伸缩及多屏行为。

手工验收
1. 打开浏览器，确认猫咪显示在上层且打字焦点不被抢走。
2. 自动隐藏任务栏：鼠标移到底部，确认猫咪随任务栏升起；移开后回落。
3. 从猫咪脚下移到底边，确认仍能唤出任务栏。
4. 在不同缩放比例的显示器之间拖动，确认落脚位置正确。
5. 观察两轮眨眼，确认循环边界不再直接切换到不同静止帧。
6. 右键分别试播舔爪、向左走、向右走，观察两侧不同毛色以及屏幕边缘停步。
7. 散步时拖动或打开托盘菜单，确认猫咪暂停；取消随机活动后确认不再自行散步。
8. 更新后先退出旧程序，再启动 start_cat.bat；右键“走路效果”逐一切换五种版本，
   分别手动选左右走并观察两圈。退出再重启，确认仍是上次选的效果。
9. 启用巡逻，观察完整的左边缘→右边缘→左边缘路线，确认中途休息、舔爪后继续原方向。
10. 在新 8 帧模式下以桌面固定图标或任务栏分隔线为参照，观察落地支撑脚是否滑动；
    比较 160、220、300 三种尺寸，并观察第八帧回到第一帧。
11. 让猫跨屏，确认不会在第一块屏幕边缘折返；测试副屏负坐标、不同缩放和高低排列。
    猫在副屏时断开该显示器，确认回到仍连接的屏幕。
12. 从左右走路分别选择坐下，确认经过转身和屈膝落座，头部没有突然变大；
    起步前先起身转向，转身中打开菜单会暂停，改选另一个动作从当前显示姿势衔接。
13. 先选择仰躺，再选择向左走，观察侧卧→趴着→坐起→转身；途中再次换动作，确认旧动作取消。
14. 按住猫咪拖动，观察四肢下垂、无贴地阴影、横向晃动；停住后稳下来，松手没有回正跳帧。
15. 将浏览器向下移动以留出顶部空间，把猫咪脚下拖到窗口上沿松手；确认经过落稳再趴下。
    移动、缩放窗口，观察猫咪跟随；再测试跨屏、不同缩放、窗口最小化、关闭及顶沿被遮挡。
16. 窗口待机时打开托盘菜单，确认菜单不被猫遮住；选择回到底沿后恢复任务栏与多屏巡逻。
17. 在浅色和深色桌面上检查坐姿、走路和趴姿阴影；拖动／自由悬浮时应隐藏贴地阴影。
18. 窗沿选择骑坐，确认两脚、尾巴垂在窗沿下方；选择左右走，确认起步时收脚、脚底贴住窗沿。
    开启巡逻后观察走一段再休息，窗口变窄或边沿有遮挡时不会继续走出有效支撑区域。
19. 选择“从窗口跳下”，检查蹲低、逐渐加速的下降、前爪着地和屈腿缓冲；中途按住可重新抱起。
    再测试准备时移动／关闭支撑窗口，以及不同高度的窗口、自动隐藏任务栏和三种猫咪尺寸。

自主生活节奏（行为层，独立于每个动画）
- 默认从休息开始：100～220 秒，以趴卧、侧卧、仰躺为主，偶尔坐着、舔毛；不自动走路或换窗口。
- 休息结束随机进入日常活动（25～55 秒）或突然活跃（8～16 秒）。日常活动包含巡逻、停留和探索窗口。
- 突然活跃时移动速度与步频同步为日常的 1.45 倍，保留脚掌锚点；地面和窗沿共用同一活动程度。
- 撒欢结束必经放松恢复（25～45 秒），之后回到休息。日常活动结束通常恢复，也可能短暂撒欢。
  恢复期间选择休息姿势，不开启新的自动跳跃；已在空中的动作先完成落地，再处理休息转换。
- 每次休息姿势停留约 25～55 秒，恢复阶段约 10～20 秒，避免频繁换姿势；模型长期以安静为主。
- 右键“活动程度”显示当前状态，可选“休息一会儿／起来活动／撒欢一阵”，之后继续自然循环。
  选择活动程度会开启自主生活；关闭自主生活则暂停节奏。菜单和拖动期间也暂停计时。
- 手动选择普通动作后，20 秒内不被活动阶段切换强制打断；自由悬浮仍不自动走路或爬窗。
- activity_rhythm.py 管理长期节奏；pet_logic.py 选择阶段内动作；跳跃、转换和窗口几何仍由原逻辑处理。
